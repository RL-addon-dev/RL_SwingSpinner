# Changelog

## v1.0.0

First release. The swing timer spinners from RL: QoL Tweaks, as their own addon with their own
settings.

- One spinner each for the main hand, off hand and ranged weapon, placed in Edit Mode. Click one
  there to change its size and opacity.
- Spinner Visibility: show them while each swing recharges, in combat, with an enemy targeted,
  or always, in any mix.
- Idle Style, Spinner Behavior and an optional countdown.
- The game's own colors, or a color of your choice, plus a size and opacity for each spinner.
- The off hand can share the main hand's circle as its left half, like the gamepad UI.
- Works in the gamepad UI, hiding the reticle's own swing timer while any spinner is on.
- The game's swing timer bars are left alone. If RL: QoL Tweaks turned them off, they're turned
  back on once.
- Takes over the spinners' positions from RL: QoL Tweaks.
